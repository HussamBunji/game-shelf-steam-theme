Download for Windows
Free installer · about a minute All releases

In Desktop Mode, open Konsole (or any terminal) and paste this one line:

$ curl -fsSL https://raw.githubusercontent.com/yousf612-alwazzan/game-shelf-steam-theme/main/install-linux.sh | bash

Needs Millennium installed first (the free theme loader, from steambrew.app). No sudo, nothing outside your home folder. Theme files only: GameShelf-Theme.zip in the releases.

    03Install

    About a minute,
    start to finish.

    1. 1

      Download

      One small installer file. Free, no account, no sign-up.

    2. 2

      Run it

      If you don't have Millennium (the free, open-source theme loader for Steam), it installs it for you, then restarts Steam.

    3. 3

      Pick your themes

      Tick the looks you like. Change your mind any time from the THEMES button inside Steam.

    If Windows shows "Windows protected your PC"

    Click More info, then Run anyway. Windows shows this for new apps that aren't code-signed yet. The installer is open source; you can read every line on GitHub.
